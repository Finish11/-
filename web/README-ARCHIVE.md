# Веб-панель «Пульс сети»

Исходники публичного сайта-компаньона: https://puls-seti-tore.arcada.app

Отдельный проект на Vite + React + TypeScript + Tailwind CSS 4. Он не собирается
вместе с Android-приложением и не входит в его бандл: это статический сайт со
своим `package.json` и своей сборкой на Vercel. Папка `web/` лежит в этом
репозитории как архив исходников, чтобы код не жил только в облаке.

## Что внутри

- `src/` — страницы (обзор, сканер, каталог, отчёты, сбои, VPN-монитор, история,
  «О проекте»), общие компоненты и CSS дизайн-системы сайта.
- `public/data/reports.json` — общая лента отчётов, читается с того же сервера.
- `public/LICENSE-source.txt` — текст лицензии, который раздаёт сайт.
- `scripts/qa.mjs` — сквозная проверка со скриншотами и поиском горизонтального
  переполнения; `scripts/package-source.mjs` собирает архив с исходниками для
  страницы «Скачать полный код».

## Как запустить

```bash
cd web
npm ci
npm run dev
```

Требуется Node.js 24.x (зафиксировано в `package.json`). Ключи, `.env` и база
данных не нужны: сайт статический.

## Связь с приложением

Дизайн сайта — источник палитры и типографики приложения: тёплый тёмно-зелёный
фон, «бумажная» светлая тема, Golos Text для текста и Manrope для заголовков.
Скрипты сайта в бандл приложения не попадают: у них разные задачи и разный
уровень доверия к данным.
