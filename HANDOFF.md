# ПульсСети — состояние после прохода 1.5.0

Дата прохода: 5 ноября 2026. Рабочая ветка Arena: `arena/e6ffad86-repo`.
База прохода: `7a69a61` (1.4.1). Актуальный коммит смотреть через `git log -1 --oneline`.

## Главные правила

- Интерфейс по-русски, спокойные формулировки, мобильная ширина 390 px в первую очередь.
- В APK только реальные сетевые измерения. Ответ-заглушка и чужой TLS не считаются
  доступностью. Нельзя подставлять вывод вместо объяснения.
- В новой установке Android нет демо-замеров, демо-VPN и выдуманных региональных отчётов.
  Демо-набор остаётся только в браузерном предпросмотре и явно помечен.
- Пороги вердиктов и узлов без обоснования не менять. Пинг TCP не доказывает работу туннеля.
- Перед коммитом: `npm run typecheck`, `npm run test:core`, `npm run build`, `npm run build:demo`.
- Пуш только в текущую ветку Arena. Если обычный TLS-пуш падает:
  `git -c http.version=HTTP/1.1 push origin arena/e6ffad86-repo`.
- APK: `gh workflow run android-apk.yml --ref arena/e6ffad86-repo`,
  проверка: `gh release view android-latest`.

## Что сделано в 1.5.0

1. **Вердикт и фильтр.** `src/lib/scanner.ts` считает `intercepted` неоткрытым даже в
   старой записи со статусом ok/slow; счётчики и средний отклик это тоже учитывают.
   Сценарий со всеми подменами больше не может стать `OPEN_INTERNET`. В
   `ScannerView.tsx` чип «Недоступны» заменён на «Подмена». Есть регрессионные тесты.
2. **Скорость.** `realScan.ts`: до 32 параллельных проб, первый таймаут 4,5 с,
   повтор 2,5 с только для таймаута. `siteProbe.ts`: четыре контрольных адреса
   выполняются параллельно и ждут первый успех. Пороги ok/slow не менялись.
3. **Тип сети.** Нативный `ApkUpdaterPlugin.networkKind` смотрит
   `NetworkCapabilities` и underlying networks VPN. `networkInfo.ts` использует его
   до стандартного Capacitor Network. `App.tsx` обновляет контекст при смене сети.
   Добавлено разрешение `ACCESS_NETWORK_STATE`.
4. **Мои сервисы.** `QuickPicks.tsx`: сетка 2/3/4 колонки вместо одной прокручиваемой
   строки; перетаскивание за ручку работает pointer-событиями на телефоне, стрелки
   доступны с клавиатуры; порядок хранится в `pulsenet_quick_order`. Подмена подписана
   отдельно. ChatGPT не объявляется обязательно заблокированным: проба проверяет сайт,
   не вход/API/сообщения.
5. **Сохранение после обновления.** `localApi.ts` восстанавливает и сохраняет состояние
   через `@capacitor/preferences` (SharedPreferences), localStorage остаётся резервом.
   Сохраняются подписки и их URL, узлы, пинги, сайты, замеры, профиль и отчёты. При
   обновлении каталог пополняется без сброса пользовательских изменений. Старые версии
   состояние не сохраняли, поэтому уже потерянную подписку восстановить неоткуда;
   после повторного добавления в 1.5.0 она должна переживать следующие обновления.
6. **Подписка и пинг.** Дедупликация учитывает полную ссылку (UUID/ключи), поэтому разные
   конфиги с одинаковыми именем и хостом не исчезают. При синхронизации совпадающие
   узлы сохраняют ID, основной флаг и прошлые замеры. Пинг всех и одного узла переведён
   на единый реальный TCP-connect, 12 потоков, таймаут 4 с. Медленный ответ — degraded,
   не blocked; «отвечают» включает online + degraded. Сортировка «Сначала быстрые»
   включена по умолчанию, можно вернуть порядок подписки.
7. **Отчёты без выдуманной публики.** В Android региональные отчёты — реальные записи
   пользователя с именем и временем, сохранённые на устройстве. Через
   `@capacitor/share` их и текст замера можно отправить в мессенджер или на сайт.
   Общего интернет-фида по-прежнему нет: для него нужен публичный backend, которого у
   автономной APK нет. Интерфейс это прямо объясняет и не называет локальное сохранение
   публикацией в общей сводке.
8. **CI.** Workflow перед APK запускает typecheck, core-тесты и web build. Версия
   обновлена до 1.5.0; release notes переписаны под этот проход.

## Архитектура и ограничения

- `src/main.demo.tsx` + `src/demo/localApi.ts` используются и в браузерном preview, и в
  автономной APK. Ветка `isNativeApp()` определяет отсутствие демо-данных в Android.
- `src/lib/realScan.ts` и `siteProbe.ts` — реальные пробы сайтов через CapacitorHttp.
- `src/lib/nodePing.ts` + `ApkUpdaterPlugin.tcpProbe` — настоящий TCP-connect без VPN.
- Настоящего VPN-туннеля (VpnService + sing-box/xray) нет. QR/export только передают узел
  внешнему клиенту. Никакие TCP-замеры нельзя выдавать за проверку работы через узел.
- Региональные отчёты в APK локальные, не общая карта пользователей. Для общей карты нужен
  отдельно развёрнутый HTTPS backend с модерацией и политикой приватности.
- Проверка сайта ChatGPT не означает доступность авторизации, API и отправки сообщений.
- Нативные сетевые транспорты, установка APK и Sharesheet окончательно проверяются на
  телефоне; в песочнице нет Java/Android SDK и доступа к устройству.

## Проверка и следующий проход

- Core: `npm run test:core` (подмена, открытый сценарий, ChatGPT, дедупликация, sing-box flow).
- Для браузера: `npm run build:demo`, затем `npx serve demo-dist -l 4173`.
- Проверять 390 px: карточки не обрезаны, две колонки, ручка перетаскивания, фильтр
  «Подмена», сортировка узлов, пустая история без демо в нативном режиме.
- После установки APK на телефоне проверить: LTE без Wi-Fi и под VPN, скорость полного
  замера, число узлов конкретной подписки (ожидаемые 79), перезапуск и обновление поверх
  без потери подписки, системное меню «Поделиться».
- Если панель снова отдаёт меньше узлов, нужен её JSON/текст без секретов либо статистика
  до/после дедупликации. Нельзя «добивать» число выдуманными конфигами.
